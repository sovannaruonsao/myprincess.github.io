EL SAMNANG — BIRTHDAY WEBSITE
================================

FILES
- index.html : website structure and Khmer/English content
- style.css  : pink romantic design and responsive layout
- script.js  : interactions, countdown, music controls, petals and wish effect
- music.mp3  : ADD YOUR OWN MUSIC FILE HERE (not included)

HOW TO RUN
1. Extract this project folder.
2. Add an MP3 file and rename it exactly: music.mp3
3. Open index.html in Chrome, Edge, Safari, or Firefox.
4. Tap "Open My Gift" to start the experience and music.

IMPORTANT
- Browsers usually block autoplay until the visitor taps/clicks. This site starts music after "Open My Gift".
- Replace the illustrated memory cards with real photos later if you want.
- The countdown is set to November 17, 2026, Cambodia time (UTC+7).
- To change the date, edit the `birthday` value in script.js.
- For best Khmer typography, keep an internet connection so Google Fonts can load.

PUBLISH ONLINE
You can publish this folder using GitHub Pages, Netlify, or another static website host.
Upload index.html, style.css, script.js, and your music.mp3 file together.
